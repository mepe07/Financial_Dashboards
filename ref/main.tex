\section*{Resumo}
Este projeto visa o desenvolvimento de uma aplicação web interativa para o processamento, validação e análise visual de ficheiros financeiros no formato proprietário PS2. A solução foi implementada utilizando a linguagem Python e a framework \textit{Shiny for Python}. O sistema permite a leitura de múltiplos ficheiros, a deteção automática de registos inválidos e a apresentação de indicadores de gestão (KPIs) através de dashboards dinâmicos. A arquitetura modular adotada garante a escalabilidade e a facilidade de manutenção do código.

\vspace{1cm}
\textbf{Palavras-chave:} Python, Shiny, Análise de Dados, PS2, Visualização.

\section{Introdução}
O processamento de grandes volumes de dados financeiros requer ferramentas que garantam não apenas a integridade da informação, mas também uma visualização clara para a tomada de decisão. O presente relatório documenta o desenvolvimento de uma ferramenta capaz de interpretar ficheiros com extensão \texttt{.ps2}, validar a sua estrutura interna e apresentar os resultados num dashboard web.

\subsection{Objetivos}
Os principais objetivos deste trabalho foram:
\begin{itemize}
    \item Desenvolver um algoritmo de leitura (parser) robusto para ficheiros PS2.
    \item Implementar mecanismos de validação para isolar ficheiros corrompidos.
    \item Criar uma interface gráfica reativa para filtragem de dados por data, entidade e ficheiro.
    \item Visualizar métricas chave, como o Top de Clientes (Pareto) e a Evolução Temporal.
\end{itemize}

\section{Arquitetura da Solução}
O projeto foi estruturado seguindo princípios de modularidade, separando a lógica de processamento de dados da interface do utilizador.

\subsection{Estrutura de Ficheiros}
A organização do projeto segue a seguinte hierarquia:
\begin{itemize}
    \item \texttt{app.py}: Ponto de entrada da aplicação Shiny (Front-end e Lógica de Servidor).
    \item \texttt{src/}: Módulo contendo a lógica de negócio.
    \begin{itemize}
        \item \texttt{ler\_ficheiros\_ps2.py}: Responsável pela leitura crua dos dados.
        \item \texttt{validar\_dados.py}: Algoritmo de deteção de erros estruturais.
        \item \texttt{converterParaPandas.py}: Transformação e limpeza de dados.
    \end{itemize}
    \item \texttt{data/}: Diretório de armazenamento dos ficheiros \texttt{.ps2}.
    \item \texttt{docs/}: Documentação técnica gerada automaticamente pelo \texttt{pdoc}.
\end{itemize}

\section{Implementação Técnica}

\subsection{Tratamento e Limpeza de Dados}
A leitura dos dados utiliza dicionários para armazenar a informação de cabeçalhos, movimentos e rodapés. Um aspeto crítico foi a otimização da filtragem de ficheiros inválidos antes da conversão para \texttt{Pandas}, utilizando \textit{List Comprehensions} para eficiência:

\begin{lstlisting}[caption={Filtragem de dados inválidos no arranque}]
# Criar uma lista contendo APENAS os ficheiros válidos
dados_validos = [
    dado for dado in dados_brutos
    if dado.get("Origem") not in ficheiros_invalidos
]
\end{lstlisting}

\subsection{Interface e Reatividade (Shiny)}
A interface foi construída com \texttt{Shiny for Python}, utilizando um layout de barra lateral (\textit{sidebar}) para filtros globais.
Destaca-se a implementação de um sistema de notificações avançado que comunica entre Python e JavaScript para animar o botão de alertas quando erros são detetados.

\begin{lstlisting}[caption={Comunicação Assíncrona Python-JavaScript}]
@reactive.effect
async def controlar_animacao_botao():
    erros = store_invalidos()
    tem_erro = True if erros else False
    
    # Envia sinal ao JS para ativar classe CSS
    await session.send_custom_message(
        "gerir_animacao_sino", 
        {"id": "btn_notificacoes", "ativar": tem_erro}
    )
\end{lstlisting}

\subsection{Deteção de Erros}
O sistema é capaz de identificar ficheiros que não cumprem o formato esperado. Ao clicar no botão de notificações, o utilizador recebe uma lista detalhada dos ficheiros rejeitados, garantindo que os gráficos não apresentam dados enviesados.

\section{Conclusão}
O projeto resultou numa ferramenta funcional e robusta. A utilização de Python permitiu um processamento rápido dos ficheiros de texto, enquanto o Shiny ofereceu uma interface moderna sem a necessidade de tecnologias web complexas (HTML/CSS) manuais.
Como trabalho futuro, sugere-se a integração com uma base de dados SQL para persistência histórica dos dados processados.
