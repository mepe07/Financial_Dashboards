\section{Introdução}
O processamento de dados financeiros exige ferramentas robustas. Este relatório documenta uma solução em Python para leitura e análise de ficheiros PS2. O projeto utiliza a biblioteca \textit{Shiny} \cite{shiny2024} para a interface gráfica e \textit{Pandas} \cite{mckinney2012} para a manipulação de dados.

\subsection{Objetivos}
Os objetivos principais definidos para este projeto foram:
\begin{itemize} % Uso de Itemize (Requisito)
    \item Desenvolver um \textit{parser} de ficheiros de texto.
    \item Criar validações automáticas de integridade.
    \item Apresentar dados em \textit{dashboards} interativos.
\end{itemize}

\section{Arquitetura e Organização}
A organização do projeto segue o padrão modular MVC (Model-View-Controller).

\subsection{Algoritmo de Filtragem}
Uma das funcionalidades críticas é a filtragem de ficheiros corrompidos antes da conversão para \textit{DataFrames}. O Código \ref{lst:filter} demonstra o uso de \textit{List Comprehensions} para eficiência.

% LISTAGEM DE CÓDIGO (REQUISITO)
\begin{lstlisting}[caption={Filtragem de dados inválidos}, label={lst:filter}]
# Criar uma lista contendo APENAS os ficheiros válidos
dados_validos = [
    dado for dado in dados_brutos
    if dado.get("Origem") not in ficheiros_invalidos
]
\end{lstlisting}
